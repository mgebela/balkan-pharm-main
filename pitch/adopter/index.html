05 · Honest limits

What this is not.

Read this slide before you decide anything. If it makes you walk away, it did its job.

What’s real today

  • Real plants, journals, in-app photos, and illness checks
  • Real transactions on Solana’s public test network
  • The same trail the grower sees
  • Public docs and a published risks page

What it isn’t

  • $GROWTOO has no monetary value — it’s a test asset
  • No yield promise, no return, no financial advice
  • Harvest redemption is specified but still mocked
  • Not trustless yet — the operator reviews mints; Market also needs a 14-day saved-care trail, not a plant oracle
