# growtoo community working files

Drafts and learning notes for the community-builder agent. Nothing here is published until a human approves it.

| Path | What goes here |
| --- | --- |
| `queue/YYYY-MM-DD.md` | Daily reply and post drafts |
| `log.md` | Metrics and session notes |
| `weekly/YYYY-Www.md` | Sunday learning report |
| `claims-pending.md` | New public facts waiting for approval |

Approved product facts live in `community-agent/config/product-facts.md`. Run the agent from `community-agent/` (`npm run daily`). Review cards land in `queue/`.
