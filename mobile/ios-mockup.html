What changes going native

The web app's sidebar + bottom-nav hybrid collapses into five tabs with a centre action. Notes below track with the screen on the phone.

Journal — the home tab

  • Large title collapses to a 44 pt bar on scroll — replaces the web header row.
  • Today card is the same daily-status strip, promoted to the first card.
  • Wax-seal rail keeps the catalog motif; horizontal scroll instead of a grid.
  • Recent notes become an inset-grouped list with SF-style chevrons.
  • Native adds: Lock Screen widget for the seal rail, Live Activity while a seal confirms.

Plants

  • Weather widget shrinks to one row — full forecast moves behind a tap.
  • Plant cards carry state as pills (Sealed, Water due, Listed).
  • Swipe actions on each card: water, photo, archive.
  • Pull-to-refresh replaces the Refresh button.

Plant detail

  • A pushed screen with a back chevron, not a modal — deep-linkable from notifications.
  • On-chain facts sit in their own group, tx hashes in JetBrains Mono as on web.
  • Care trail is the journal filtered to one plant.

Market

  • Simple / Advanced stays as a real UISegmentedControl.
  • Invest confirms with Face ID before the wallet round-trip.
  • Wallet connect uses Mobile Wallet Adapter deep links, not an injected provider.
  • App Store note: token flows must read as utility/test, never as investment product.

Grow coach

  • A messages screen — bubbles, sticky composer, camera button inline.
  • Photo diagnosis is one tap from the composer; the capture returns straight into the thread.
  • Coach suggestions write into Today, which drives notifications.

Tokenise

  • Reachable from Account and from a plant — it isn't frequent enough for a tab.
  • Stage picker as a segmented control; wallet state shown before the irreversible action.
  • Sealing shows a Live Activity until the devnet tx confirms.

Today

  • The checklist from the web app, now the source for the daily local notification.
  • Also renders as a Home Screen widget and a Lock Screen complication.

Inbox

  • Mirrors push notifications; each row deep-links to its plant or offer.
  • Confirmations, adoptions and stage milestones are the three push categories.

Camera

  • Full-bleed AVFoundation capture — the web camera's biggest upgrade.
  • Mode strip picks what the shot is for: journal photo, coach diagnosis, or seal evidence.
  • Frame guide keeps diagnosis photos consistent enough to compare week to week.

Settings — Appearance

  • Three values, one preference: Light, Dark, System — the same shape as UIUserInterfaceStyle.
  • Dark stays the default. It's the identity the catalog system was drawn for; light is the accommodation, not the baseline.
  • Light isn't dark-inverted: brass drops to #7d6024 for text and icons so it stays legible on paper, while filled buttons keep the gold.
  • Switching is instant and themes only the device here — the page around the phone stays dark.

Notes

Tokens are copied from app/styles/app.css — brass #c9a55e, forest #0f1a12, cream #f3efe6. Type is the system stack, which resolves to real SF on Apple hardware.

Metrics are iOS points at 393 × 852 (iPhone 16 / 15 Pro class): 59 pt top inset, 44 pt nav bar, 49 pt tab bar, 34 pt home indicator.

Android would keep the same screens on Material 3: bottom bar without the raised FAB, an extended FAB on Journal, and back-gesture navigation.
