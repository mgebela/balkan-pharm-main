    Questions people actually ask

    Straight answers before you start

    Start with the journal questions. Crypto details come later — only if you want them.

    Do I need to know anything about crypto to use this?

    No. The journal is free and usable with no wallet at all. A Solana wallet (Phantom or Solflare) is only needed if you want to mint or adopt on the test network.

    Is this only for licensed commercial growers?

    No. The journal is aimed at cannabis growers (a plant or a few, or a full room), including places where cultivation rules are opening up. Always follow the law where you grow; growtoo is a documentation tool, not legal advice.

    Who verifies that a journal entry is real, not fabricated?

    Today, the platform operator reviews journal progress before minting. The live-network roadmap moves this toward stronger attestations so no single party has to be trusted forever. Details live in the trust model docs.

    Is this legal? What happens with an actual harvest?

    Redemption converts a harvest-stage token into its real-world counterpart, subject to applicable regulation in the grower’s jurisdiction. Today redemption is specified but still mocked on the test network, not a live fulfillment pipeline. Read Risks & scope for the honest limits.

    Why build on a test network instead of going live with real money?

    So the system (journal proof, minting, escrow, redemption) can be battle-tested in the open first. Growers and adopters can see exactly how it works before anything real is at stake. “Devnet” is Solana’s public test network — same tools, no real value.

    Is $GROWTOO worth anything right now?

    No. It’s a test-network token with no monetary value. It exists so the optional mint → verify → adopt flow can be tested publicly before real value is on the line.

    What happens to my $GROWTOO when the live network launches?

    Test-network $GROWTOO is for practicing the flow and should not be treated as transferable monetary balance. Early-grower recognition (the Founding Grower badge) is intended to carry forward; exact migration rules will be published before launch.

    When does the live network launch?

    Targeting after the harvest redemption flow ships (roadmap milestone M5 in the docs). See the architecture notes in our docs. We publish milestones, not a vague “soon.”
