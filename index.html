Questions people actually ask

Straight answers before you desk in

For anyone who has heard “RWA” and “Devnet” and still wants the plain version.

Is $GROWTOO worth anything right now?

No. It’s a Devnet test token with no monetary value. It exists so the whole mint → verify → trade flow can be tested and shown publicly before real value is on the line.

Why build on Devnet instead of going live with real money?

So the system (journal proof, minting, escrow, redemption) can be battle-tested in the open first. Growers and adopters can see exactly how it works before anything real is at stake.

When does mainnet launch?

Targeting after the M5 redemption flow ships. See the architecture and roadmap notes in our RWA docs. We publish milestones, not a vague “soon.”

Is this legal? What happens with an actual harvest?

Redemption converts a harvest-stage token into its real-world counterpart, subject to applicable regulation in the grower’s jurisdiction. Today redemption is specified but still mocked on Devnet, not a live fulfillment pipeline. Read Risks & scope for the honest limits.

What happens to my $GROWTOO when mainnet launches?

Devnet $GROWTOO is for testing the flow and should not be treated as transferable monetary balance. Founding Grower recognition is intended to carry forward; exact mainnet migration rules will be published before launch.

Who verifies that a journal entry is real, not fabricated?

Today, the platform operator reviews journal progress before minting. The mainnet roadmap moves this toward stronger attestations so no single party has to be trusted forever. Details live in the trust model docs.

Do I need to know anything about crypto to use this?

No. The journal is free and usable with no wallet at all. A Solana wallet (Phantom or Solflare) is only needed if you want to mint or trade.

Start with the journal. The rest is optional.
